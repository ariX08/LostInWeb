# LostInWeb

A beautiful, addictive single-page web app for pure internet discovery.

**Every click throws you into a carefully curated random interesting website** — tools, games, articles, interactive experiments, obscure gems, and mild chaos.

## Live Demo

Open `index.html` directly in a browser, or serve the folder with any static server.

## Features

- **266+ curated sites** across Tools, Games, Articles, Weird, Interactive, Creative, Science, Art
- Large glowing **Get Lost** button with pulse animation
- Dark cyber-aesthetic with neon accents and particle field
- Local history drawer + lost counter (persisted)
- Category filters
- Keyboard shortcut (Space / Enter)
- Soft sound design (muteable)
- **Deeper Web** mode unlocks after 10 jumps
- Same-tab / New-tab toggle
- Fully responsive & accessible

## Tech

Pure frontend: HTML + CSS + vanilla JS. No build step, no dependencies.
